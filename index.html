Ergonomicon Backup

The off-site backup of Ergonomicon. Every night it stores an encrypted copy of Ergonomicon’s data in its owner’s own Google Drive, so the data survives the loss of the server it runs on.

What Ergonomicon is

Ergonomicon is a personal research tool built and run by Nicolas Gobet on a server in his home. It collects public job postings from the career pages of medical-technology and pharmaceutical companies, organises them into a taxonomy of roles and skills, and helps its owner follow the job market in his field. Nobody else uses it, and it has no public interface.

Its data — hundreds of thousands of postings collected over time, many of which are no longer online — cannot be collected again. That is why it needs a backup outside the house.

What Ergonomicon Backup does

1

Nightly upload

At 05:30 the home server sends the night’s database backup and the archive of collected pages to one folder in the owner’s Google Drive.

2

Encrypted first

Everything is encrypted on the home server before it leaves. Google stores only encrypted data and cannot read it.

3

Only what changed

Data already uploaded is not sent again, so a night costs a few hundred megabytes rather than the full database.

4

Automatic retention

7 daily, 4 weekly and 12 monthly copies are kept; older ones are deleted from the backup folder.

5

Weekly verification

Every Sunday a sample of the stored data is downloaded again and checked for integrity.

6

Restore

If the server is lost, the owner downloads the files from the same folder and decrypts them on new hardware.

How it uses Google user data

Ergonomicon Backup connects to exactly one Google account — its owner’s — and requests the narrowest Google Drive permission available.

Google user data — in short

Permission
drive.file: access only to the files and folders Ergonomicon Backup creates itself.
Used to
create one backup folder in the owner’s Google Drive, upload encrypted backup files into it, read them back to verify and restore, and delete expired ones.
Cannot see
any other file in the Drive, Gmail, contacts, calendar, photos, or profile data.
Shared with
nobody. Not sold, not used for advertising, not used to train models.

Full details: privacy policy.

Who can use it

Only its owner. Ergonomicon Backup is not a public service: there is no sign-up, no account for anyone else, and no download. This site exists to describe the tool transparently, as Google requires for any application that uses Google’s APIs.
