Ergonomicon Backup

Security

Designed so that a copy in the cloud reveals nothing, and so that the tool can touch as little as possible.

Encryption before upload

All data is encrypted on the owner’s server with restic (AES-256 in counter mode, authenticated with Poly1305) before it is sent. The key is derived from a password that exists only on the server and in the owner’s password manager. Google, and anyone with access to the Drive folder, sees only encrypted files of random content.

Least-privilege access to Google Drive

Ergonomicon Backup requests https://www.googleapis.com/auth/drive.file, the narrowest Google Drive permission. With it, Google lets the tool see only files and folders it created. It cannot list, open or change anything else in the Drive, and it requests no other Google data at all.

Credentials

  • The Google access token is stored only on the owner’s server, readable by its administrator account alone.
  • All connections to Google use HTTPS.
  • The application’s Google client credentials are not published and not shared.

Revoking access

The owner can withdraw the tool’s access at any moment at myaccount.google.com/permissions. Deleting the backup folder in Google Drive removes all stored data.
