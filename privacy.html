Ergonomicon Backup

Privacy policy

Effective 11 October 2026

1. Who is responsible

Ergonomicon Backup is a personal tool developed and used by Nicolas Gobet, Switzerland (1303sbig@gmail.com). It is used only with his own Google account and is not offered to other users.

2. Google user data accessed

The tool requests one permission: https://www.googleapis.com/auth/drive.file. It gives access only to files and folders that Ergonomicon Backup itself creates in the owner’s Google Drive. It gives no access to any other file, nor to Gmail, contacts, calendar, photos or any other Google service. The tool does not request profile information.

3. How the data is used

The permission is used solely to:

  • create one folder for backups in the owner’s Google Drive;
  • upload encrypted backup files into that folder;
  • list and download those files to verify their integrity and to restore data;
  • delete backup files from that folder once they exceed the retention period.

Google user data is not used for any other purpose: not for advertising, profiling, analytics, or training of artificial-intelligence or machine-learning models.

4. Sharing and transfer

No Google user data is shared with, sold to, or transferred to any third party. The backup files remain in the owner’s own Google Drive.

5. Storage and protection

  • Backup files are encrypted on the owner’s server before upload (restic, AES-256). The key never leaves the owner’s control; Google stores only encrypted data.
  • The Google access token is stored only on the owner’s server, readable by its administrator account alone.
  • All transfers to Google use HTTPS.

6. Retention and deletion

Backups are kept on a fixed schedule (7 daily, 4 weekly, 12 monthly) and older ones are deleted automatically. Access can be revoked at any time at myaccount.google.com/permissions; deleting the backup folder removes all stored data.

7. Compliance with Google’s policy

Ergonomicon Backup’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. Website

This website sets no cookies, uses no analytics and loads no third-party content. It is hosted on GitHub Pages, which may keep standard server logs.

9. Changes

Changes to this policy are published on this page with a new effective date.
