Ergonomicon Backup

How it works

Four layers protect Ergonomicon’s data. Ergonomicon Backup is the last one: the copy that lives outside the house.

The path of one night’s backup

Step by step

  1. 04:00 — local backup. The server writes a consistent copy of Ergonomicon’s database to a second disk and checks that it can be read back.
  2. 05:30 — encryption and deduplication. The open-source tool restic splits the new data into pieces, skips those already stored, compresses and encrypts the rest on the server.
  3. Upload. The open-source tool rclone sends the encrypted pieces to the backup folder in the owner’s Google Drive, using the drive.file permission.
  4. Retention. Copies older than the retention schedule are removed from the folder.
  5. Sundays — verification. A sample of the stored data is downloaded and checked.
  6. Monitoring. Each run reports success or failure to the owner, so a backup that stops is noticed within a day.
